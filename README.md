Autorska implementacja wzorca Observer.

Implementacja w fabule sklepu wysyłającego informację do zrejestrowanych obserwatorów o aktualnej super ofercie. Dla uproszczenia oferta zawiera tylko jeden produkt. 
Obserwator (klient sklepu) po otrzymaniu powiadomienia pobiera ofertę (teoretycznie nie musi). 
Jeśli jest to rower, to wykonuje swoją akcję biznesową - wyraża swój entuzjazm i może pójdzie obejrzeć, a nawet kupić ;) - w przeciwnym razie ignoruje ofertę.

Jest to prosta, ale niebanalna wersja wzorca.

Zawiera testy jUnit5.

Zawiera autorskie opracowanie teorii wzorca Observer, w tym autorski schemat UML (uwaga: rózni się od znajdywanych w sieci).
